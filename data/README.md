# Local datasets

Place your own authorized copies of `goodreads_books.json.gz`, `goodreads_interactions.csv` and `user_id_map.csv` here. The code expects line-delimited book JSON with `book_id`, `title` and optional `image_url` / `ratings_count`; training reads the original interaction CSV fields. Obtain Goodreads / UCSD Book Graph datasets under the publisher's terms: https://cseweb.ucsd.edu/~jmcauley/datasets/goodreads.html . Do not upload dataset files or real account mappings to this repository.
